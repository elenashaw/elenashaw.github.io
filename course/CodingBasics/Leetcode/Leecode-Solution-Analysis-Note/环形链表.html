快慢指针+Floyd判圈： 环形链表

链表 #双指针 #Floyd判圈算法

Problem: 142. 环形链表 II

思路

快慢指针+Floyd判圈算法

Floyd判圈算法

算法过程

  • 快指针fast, 慢指针slow

  • 过程分析

  • 变量设置

    • 设时间为T1
    • 设起点到环入口的距离为m
    • 设环的长度为n
    • 设两个指针第一次在环内A点相遇，且环入口到A点的距离为a

  • 第一次相遇

    • 相遇的时候，由于fast很快，肯定比slow多走了k圈，距离为kn
    • 而且slow不可能已经走完一圈
    • 两个指针走的路程极其表达式
    • fast = 2 T1 (速度时间) = m+a+kn（环以外的直线距离+A点到环入口的距离+比slow多走的圈
    • slow = T1 = m+a
    • 所以m+a = kn
      • 这意味着，当位于A点的slow（距离入口a） 再走m距离时，刚好到达环入口
      • 所以，指派fast到起始点，当他刚好走到入口的时候，slow恰好在这里~

  • 第二次相遇

    • 两个指针的速度都是1

### ？追问：如果快慢指针速度是其他比例会怎样，为什么选用2：1

  • 如果选用3：1， 那么等式变成

  • 3*T1=T1+kn=m+a+kn

  • 那么m+a=1/2* kn. 并不能保证m+a走完正好是整数圈

  • 经过测试，代码超时，无解（因为不能使得m+a=kn（即第一次就相遇）,对于速度相同的两个指针，永远不会相遇

  • ```C++ / * Definition for singly-linked list. * struct ListNode { * int val; * ListNode next; * ListNode(int x) : val(x), next(nullptr) {} * }; / class Solution { public: ListNode detectCycle(ListNode head) { // 快速返回无环的简单情况 if (!head || !head->next) { return nullptr; }

         ListNode* slow = head;
     ListNode* fast = head;

     // 阶段 1：检测环，使用 1:3 速度比例
     // slow 每次 +1，fast 每次 +3
     while (fast && fast->next && fast->next->next) {
         slow = slow->next;               // 慢指针走 1 步
         fast = fast->next->next->next;   // 快指针走 3 步

         if (slow == fast) {
             // 找到相遇点 → 有环
             // 阶段 2：找环的起点，必须使用 1:1 同速
             slow = head;
             while (slow != fast) {
                 slow = slow->next;
                 fast = fast->next;
             }
             return slow;  // 或者 return fast 都可以，它们现在相等
         }
     }

     // 没相遇 → 无环
     return nullptr;
 }

    }; ```

  • 如果选用4：2，那么等式变成

  • 4T1=2T1+kn=m+a+kn

    • 即：m+a=kn=偶数
    • ？疑问1：这个比例，或者更多的2i:i的比例，是否具有完备性
    • 个人认为：只要满足m+a=kn的，都是具有算法完备性的。但是前提是，第二次两个指针的速度都是1。否则会因为m,a的奇偶性，两个指针永远不会相遇
    • ？疑问2：2i:i的比例是否在遍历速度上优于2:1比例
    • 我不知道，因为2i:i的比例本身受到while条件判断的制衡。i越大，判断指针越多
    • 也许我们可以用实验试试！
    • 实验结果

  • 明显的缺点：while循环判断的条件太赘余(可以通过2^n缓解开销)

  • ```C++ //4：2 floyd circle algos class Solution { public: ListNode detectCycle(ListNode head) { // 初始检查需要覆盖更多节点，因为慢指针一次跳两步 if (!head || !head->next) return nullptr;

        ListNode *slow = head, *fast = head;

    while (fast && fast->next && fast->next->next && fast->next->next->next) {
        // 慢指针走两步
        slow = slow->next->next;
        // 快指针走四步
        fast = fast->next->next->next->next;

        if (slow == fast) {
            // 相遇后，寻找环入口的逻辑
            // 注意：在 1:2 的情况下，入口公式是 head 到入口 = 相遇点到入口
            // 在 2:4 (简化为 1:2) 的比例下，数学原理是一致的
            fast = head;
            while (slow != fast) {
                // 这里恢复成 1:1 的速度同步移动
                slow = slow->next;
                fast = fast->next;
            }
            return fast;
        }
    }
    return nullptr;
}

    }; ```

复杂度

  • 时间复杂度: O(n)
  • 空间复杂度: O(1)：两个指针O(1)

// @lc code=start
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode(int x) : val(x), next(NULL) {}
 * };
 */

class Solution {
public:
    ListNode *detectCycle(ListNode *head) {
        if (!head || !head->next) return nullptr; //trivial cases

       //创建两个指向起点的指针
        ListNode *slow = head, *fast = head;
        while(fast&&fast->next){   
            //只要 fast 触达 nullptr，说明链表有终点，必然无环

            //快指针走两步，慢指针走一步
            slow=slow->next;
            fast=fast->next->next;

            if (slow==fast){ // 两个指针第一次相遇
                slow=head;     // 将指针重新指向起点（其实这里快慢都行，但是为了逻辑一致，选择用slow
                while(slow!=fast){
                    slow=slow->next;
                    fast=fast->next;// 两个指针每次走一步
                }
                return fast;
            }
         }
        return nullptr;

    }         
};
