位运算

编程语言中的位运算

运算符 描述 规则
& 按位与 (AND) 两位全为 1，结果才为 1
| 按位或 (OR) 两位有一个为 1，结果就为 1
^ 按位异或 (XOR) 两位不同为 1，相同为 0
~ 按位取反 (NOT) 0 变 1，1 变 0（涉及补码）
<< 左移 各二进位全部左移若干位，高位丢弃，低位补 0
>> 右移 各二进位全部右移若干位，对无符号数高位补 0 
#include <iostream>
using namespace std;

int main() {
    int a = 6, b = 4;

    // Binary AND operator
    cout << "a & b is " << (a & b) << endl;

    // Binary OR operator
    cout << "a | b is " << (a | b) << endl;

    // Binary XOR operator
    cout << "a ^ b is " << (a ^ b) << endl;

    // Left Shift operator
    cout << "a << 1 is " << (a << 1) << endl;

    // Right Shift operator
    cout << "a >> 1 is " << (a >> 1) << endl;

    // One’s Complement operator
    cout << "~(a) is " << ~(a);

    return 0;
}
/*
a & b is 4
a | b is 6
a ^ b is 2
a<<1 is 12
a>>1 is 3
~(a) is -7
*/

python 和c++的区别

整数长度

  • C++：整数有固定长度（如 int 通常是 32 位）。一旦溢出，高位会被直接截断。
  • Python：整数是任意精度的（理论上无限大）。这意味着你做 1 << 100 在 Python 中不会溢出，但在 C++ 中会导致未定义行为或截断。

符号位处理 (>>)

  • C++：对于 signed 类型，右移通常是算术右移（保持符号位）；对于 unsigned 类型是逻辑右移。
  • Python：由于没有原生的 unsigned 类型，其右移始终表现为算术右移。

位运算、算数运算和逻辑运算的区别

区别

运算类型 符号示例 (C++/Py) 操作对象 结果类型 核心逻辑
算术运算 +, -, *, / 数值 (10, 3.14) 数值 模拟人类数学计算，涉及进位/借位。
位运算 &, |, ^, ~ 二进制位 (0, 1) 整数 直接操作内存中的 Bit，各比特位独立。
逻辑运算 &&, ||, ! (C++) and, or, not (Py) 布尔值 (T/F) 布尔值 处理条件判断，关注真假关系。

注意事项

  • c++和python都没有AND作为通用关键字
  • <<， >>，指向箭头就是移动方向，原地的地方需要补0

优化和加速

位运算代替$2^n$ 相关的乘除法

  • 例子
算术运算 位运算优化 说明

a * 8 a << 3 $8 = 2^3$

代替取模运算

  • 对$2^n$取模，即：x%(2^n)=，截取二进制数的最后 $n$​ 位。

  • 十进制类比： 2437349274207对1000（10^3）取模，也就是取最后除不下的3位。

  • c++ //常规的取模方法 a % (2^n) //加速的取模方法 a & (2^n-1)

  • 为什么是 & (2^n-1)

  • 其实我们只想要a二进制后面的n位

    • $2^n$的形式： 10……0,一共n+1位
    • $2^n-1$​的形式： 1……1, 一共n位
  • “按位与”（&）的规则是：1 & x = x，0 & x = 0。 这意味着：
    • 用 1 去与：保留原样
    • 用 0 去与：强制清零

判断奇偶性

比起 n % 2 == 1，使用位运算更简洁：

  • 优化：if (n & 1)
  • 逻辑：二进制数的最后一位决定了奇偶（1为奇，0为偶）。

交换两个数 (无需临时变量)

利用异或 ^ 的特性（$x \wedge x = 0$ 且 $x \wedge 0 = x$），可以在不申请额外空间的情况下交换变量：

// C++ 
a ^= b;
b ^= a;
a ^= b;
  • 设a,b初始值是A,B
  • a ^= b
  • a=A^B

  • 结果：存储了AB差异的位置

  • b ^= a

  • b = B ^ (A ^ B)=(B ^ B) ^ A= 0 ^ A = A
  • 结果： b=A
  • a ^= b
  • a = (A ^ B) ^ A = (A\^A)\^B =0 \^ B=B
  • 结果： a=B

状态压缩与权限管理

如果你有 8 个开关状态，用 bool 数组需要 8 个字节，但用位运算只需要 1 个字节（8 位）。

  • 设置第 $i$​​ 位为 1：status |= (1 << i)

  • 1 << i

    • 1 的二进制默认是 0000 0001
    • << i 表示左移 $i$ 位
    • 结果：制造出一个只有第 $i$ 位是 $1$，其余全是 $0$​ 的数字。这个数字在编程中被称为掩码（Mask）

  • |=

    • A |= B 等同于 A = A | B

    • 作用： 将第i位设置为1，而不改变别的位

    • ```mar 1010 0000 (原始状态) | 0000 0001 (第 0 位是 1 的挑针)

    1010 0001  (新状态：第 0 位成功变 1，其他位原封不动)

  • 检查第 $i$ 位是否为 1：if (status & (1 << i))

  • 清除第 $i$ 位：status &= ~(1 << i)
